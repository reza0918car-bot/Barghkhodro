# برق خودرو مهندس

اپلیکیشن آفلاین مدیریت مشتریان، خودروها، فاکتورها و گزارش تعمیرگاه.

## ساخت APK
این مخزن فایل‌های پلتفرم Android را در زمان اجرای GitHub Actions با Flutter ایجاد می‌کند.
پس از Push به شاخه `main` یا `master`، یا اجرای دستی workflow با نام **Build Android APK**،
فایل APK در بخش Actions و قسمت Artifacts قابل دریافت است.

## نکات مهم
- اطلاعات فعلی برنامه در SharedPreferences و با کلید `customers_data_v8` ذخیره می‌شود.
- پیش از نصب نسخه جدید، از داخل برنامه کد پشتیبان بگیرید.
- خروجی CSV فعلاً متن قابل جای‌گذاری در Excel است و فایل XLSX مستقل تولید نمی‌کند.
- برای انتشار عمومی، امضای اختصاصی Android (keystore) و تنظیم امن کلیدهای امضا لازم است.
